# Hotel Management System

A modern, responsive web application for managing hotel operations, built with React and Vite. This application provides a user-friendly interface for browsing rooms, making bookings, and managing user profiles.

## 🚀 Features

-   **Room Management**: Browse and view details of available hotel rooms.
-   **Booking System**: Streamlined process for booking rooms.
-   **User Profile**: Manage user information and booking history.
-   **Responsive Design**: Fully responsive layout that works seamlessly on desktop and mobile devices.
-   **Interactive UI**: Smooth navigation and interactions using modern React patterns.

## 🛠️ Tech Stack

-   **Frontend Framework**: React
-   **Build Tool**: Vite
-   **Routing**: React Router DOM
-   **State Management**: Context API
-   **Styling**: Vanilla CSS (with responsive design)
-   **Icons**: React Icons
-   **UI Components**: Hamburger React (for mobile navigation)

## 📦 Installation & Setup

Follow these steps to get the project running locally:

1.  **Clone the repository** (if applicable) or navigate to the project directory.

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Start the development server**:
    ```bash
    npm run dev
    ```

4.  **Open in Browser**:
    The application will typically run at `http://localhost:5173` (check the terminal output for the exact URL).

## 📂 Project Structure

-   `src/components`: Reusable UI components like Navbar and Footer.
-   `src/pages`: Main application views (Home, Rooms, Booking, Profile).
-   `src/contexts`: React Context definitions (e.g., RoomContext).
-   `src/Data`: Static data files.
-   `src/assets`: Images and other static assets.
